### (A) 金額の税抜化 + 3段表示
- 購買が入力する**単価＝税抜**。`unitPrice`/`amount`/`totalAmount` はすべて**税抜**で保存。
- **消費税＝floor(税抜×10%)（切り捨て）／税込＝税抜+消費税** を**表示時に算出**。
- **社長決裁しきい値（10万円）は税抜小計で判定**（`confirmQuote` の `total` がそのまま税抜小計）。
- 表示は **小計(税抜)・消費税(10%)・合計(税込) の3段**（画面/PDF/メール共通）。
- 税率は `Constants.gs` の `APP.TAX_RATE = 0.10` と、`Client.html` の `const TAX_RATE = 0.10` の**2箇所**。**必ず一致させること**。
- ヘルパー: サーバ `taxAmount_` / `grossAmount_`（Helpers.gs）、クライアント `taxOf` / `grossOf`、PDF は `helpers.tax` / `helpers.gross`（Pdf.gs で公開）。
- 変更ファイル: `Constants.gs` `Helpers.gs` `Pdf.gs` `Workflow.gs` `Email.gs` `PdfTemplate.html` `Client.html`。

### (B) 件数バッジが古い値で固定される不具合を修正
- 原因: 一覧の「↻ 更新」が `loadRows`（リスト）だけ呼び、`refreshCounts`（バッジ）を呼んでいなかった。
- 修正: `renderList`・更新ボタンで `refreshCounts().then(renderTabs)` も呼ぶ（`Client.html`）。
- 補足: `getTabCounts`（Workflow.gs:933）と `getRequests`（Workflow.gs:213〜）の**判定条件は同一**。よってフィルタのロジックバグではない。更新後もズレる場合は**申請シートの重複行**を疑う（診断関数は未実装）。

### (C) 至急承認メールのテスト用シード（メール送信なし）
- `SampleData.gs` に追加。
  - `seedExpediteTest(departmentOverride?)`: 金額入力待ち（購買見積）の申請を**3件**シート直書きで生成。`TEST-` 接頭辞。**申請→上席承認→見積依頼のメールは一切送らない**。
  - `clearExpediteTest()`: `TEST-` 行を一括削除。
- 生成後に画面で「⚡金額不要／至急」を押すと、**通常フロー通り総務部へ実メール**が送られる（ユーザー了承済み）。
- 部署は `pickTestDepartment_` が承認者マスタから**総務部長が引ける具体部署を自動選択**。

## 3. 開発時の注意点（ハマりどころ）

- **clasp push はマニフェスト差でプロンプト停止**することがある → `npx clasp push --force`。
- **構文チェックは `npm run check`**（`tools/check-syntax.js`）。`.gs` は `node --check` 不可（拡張子未対応）。
- **clasp login は失効しうる／`clasp run` は不可**（関数実行はGASエディタで手動）。
- **enum は日本語値で照合**（`Constants.gs` の日本語コード値。キー名で hasOwnProperty しない）。
- **税率は Constants.gs と Client.html の2箇所**。片方だけ変えると画面と保存/PDFがズレる。
- 未追跡の `.omc/`（OMC作業状態）は `.gitignore` 追加推奨、`Sampledata/`（社内資料docx/pdf）は取り込み要否がユーザー判断。
