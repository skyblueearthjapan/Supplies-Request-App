# 手動テストシナリオ

## 1. 初期設定

- `setupApplication()` を実行し、SpreadsheetとPDFフォルダが作成されること。
- 管理画面で管理者メール、承認者マスタ、しきい値、メール通知設定を保存できること。

## 2. 10万円以下の申請

- 合計金額が100000円以下の申請を作成する。
- 承認経路が上席者、総務部長、購買になること。
- 購買承認後に状態が完了になり、PDF URLが表示されること。

## 3. 10万円超の申請

- 合計金額が100001円以上の申請を作成する。
- 承認経路が上席者、総務部長、社長、購買になること。

## 4. 権限

- 現在承認者以外のユーザーで承認URLを開き、承認ボタンが表示されないこと。
- 直接サーバー関数を呼んでも「現在の承認者のみ承認できます。」になること。

## 5. 差戻し

- 承認者がコメント付きで差戻しできること。
- 申請者が修正して再申請できること。
- 再申請後、承認経路が再計算されること。

## 6. 通知

- 申請時に次承認者へメールが届くこと。
- 差戻し時に申請者へメールが届くこと。
- 完了時に申請者へメールが届くこと。
